Temple Donation Tracker
Overview

One day, while visiting a temple, I observed how donations from devotees were collected by the priests (archakas). The money was counted and used for temple activities, but there was no proper system to track how much was received in each denomination such as ₹10, ₹20, ₹50, ₹100, ₹200, ₹500, and others. This made it difficult to maintain accurate records and generate statements of daily collections.

To better understand the problem, I discussed the requirements with the temple staff and spent around 3–4 hours observing their workflow. Using modern AI-assisted development tools and current technologies, I quickly designed and developed this application to help record, track, and summarize temple donations in a structured and transparent manner.
