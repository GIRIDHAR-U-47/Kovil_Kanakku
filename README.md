One day, while visiting a temple, I noticed that the priests (archakas) collected offerings from devotees in a donation plate. There was no proper record showing how much was received in different denominations, such as ₹10, ₹20, ₹50, ₹100, ₹200, ₹500 and so on. To understand the problem better, I discussed the requirements with the temple archakas and spent around 3–4 hours observing their workflow. Using modern AI-assisted development tools and current technologies, I quickly designed and built a simple application that helps them record, track and generate clear statements of the collected amount, making them manage the money at ease.
